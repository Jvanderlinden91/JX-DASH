# JX-DASH

## Premium SimHub Dashboard Suite

JX-DASH is een premium dashboardproject voor de Corsair Xeneon Edge.

Ondersteunde games:

- Le Mans Ultimate
- Assetto Corsa
- Assetto Corsa Competizione
- Assetto Corsa EVO (voorbereid)
- RaceRoom Racing Experience
- rFactor 2
- Euro Truck Simulator 2
- Farming Simulator

## Dashboards

### BMW M Motorsport
- Race Dashboard
- Telemetry
- Fuel Strategy
- Tyre Management

### MAN TGX
- Digital Cockpit
- Navigation
- Truck Information
- Trailer Information

## Features

- 2550x720 Resolution
- Touch Interface
- Startup Animation
- Game Detection
- Dashboard Profiles
- SimHub Compatible
